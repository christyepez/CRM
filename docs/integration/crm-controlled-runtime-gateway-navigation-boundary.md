# CRM Controlled Runtime Gateway and Navigation Boundary

Portal Gateway and Portal navigation remain disabled for CRM productive use in P4.

## Rules

- CRM does not register productive Gateway routes.
- CRM does not enable productive Portal navigation.
- CRM may define future relative route placeholders only.
- Portal owns route exposure and menu visibility.

## Markers

- GatewayNavigationBoundaryPrepared: true.
- ProductivePortalGatewayRoutesEnabled: false.
- ProductivePortalNavigationEnabled: false.
- RuntimePortalCouplingEnabled: false.
