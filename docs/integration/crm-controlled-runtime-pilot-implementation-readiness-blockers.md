# CRM Controlled Runtime Pilot Implementation Readiness Blockers

## Blocking conditions

- Any production activation marker.
- Any CRM production-ready marker set to true.
- Any runtime Portal call or coupling enabled.
- Any productive Portal route or navigation enabled.
- Any CRM-owned SQL Server or Portal service in CRM compose.
- Any real secret, token, certificate, private endpoint, real data or real environment file.
- Any direct Portal database access, shared table or cross-domain migration.

## Markers

- ImplementationReadinessBlockersPrepared: true.
- ReadinessReviewOnly: true.
- ConditionalFutureGoExecuted: false.
