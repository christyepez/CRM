# CRM Controlled Runtime Pilot First Slice Scaffold

## Scope

The scaffold adds contracts, safe options, a disabled Portal runtime client, a local foundation status endpoint and verification tooling.

It does not enable real Portal communication, Gateway routes, navigation, Common DB runtime, SSO/OIDC, secrets, notifications, observability or production paths.
