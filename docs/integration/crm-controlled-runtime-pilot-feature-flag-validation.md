# CRM Controlled Runtime Pilot Feature Flag Validation

## Validation

The P5 feature flag names are validated as prepared documentation only. They are not wired to runtime and do not enable Portal calls, Gateway routes, navigation, providers or database runtime.

## Markers

- ControlledRuntimePilotFeatureFlagValidationPrepared: true.
- ControlledRuntimePilotFeatureFlagsPrepared: true.
- RuntimePortalCouplingEnabled: false.
- RuntimePortalCallsEnabled: false.
- ProductivePortalNavigationEnabled: false.
- ProductivePortalGatewayRoutesEnabled: false.
- CommonDbRuntimeEnabled: false.
