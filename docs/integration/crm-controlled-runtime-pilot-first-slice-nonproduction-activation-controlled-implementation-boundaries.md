# CRM Controlled NonProduction Activation Implementation Boundaries

Boundaries:

- CRM does not own Portal Auth, Menu, Permissions, Audit, Notification or Configuration.
- CRM does not access Portal database objects directly.
- CRM does not register Portal services in CRM compose.
- CRM does not enable productive routes or navigation.
- CRM does not execute activation in P24.
