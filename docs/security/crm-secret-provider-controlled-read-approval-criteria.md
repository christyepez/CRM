# CRM Secret Provider Controlled Read Approval Criteria

P2 criteria:

- NonProduction verified.
- External Secret Provider configured outside the repository.
- Least privilege access.
- Redacted logs.
- No value caching.
- No value persistence.
- No value returned by API.
- Timeout and failure handling defined.
- Rollback approved.
- Observability approved.
- Security, Architecture and DevOps approvals recorded.
