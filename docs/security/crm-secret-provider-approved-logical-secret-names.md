# CRM Secret Provider Approved Logical Secret Names

Approved logical names only:

- `crm-common-db-connection`
- `crm-portal-auth-base-url`
- `crm-portal-auth-client-id`
- `crm-portal-auth-client-secret`
- `crm-observability-endpoint`

Only names are approved. Values are not approved for source control, logs, API responses or persistence.
