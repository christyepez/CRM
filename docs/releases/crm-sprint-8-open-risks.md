# CRM Sprint 8 Open Risks

- Sprint 9 activation planning could be mistaken as production approval.
- Secret Provider runtime must prove redaction and rollback before any controlled enablement.
- Common DB runtime must avoid exposing connection strings in contracts, logs or telemetry.
- Portal Auth runtime must remain owned by PortalCorporativo and avoid CRM-owned identity.
- Locked route policy metadata must not become hidden CRUD enablement.
- Productive UI remains blocked until backend, security, data and portal gates are approved.
