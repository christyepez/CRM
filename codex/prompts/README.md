# Prompts Codex por sprint

Esta carpeta contiene prompts largos versionados para tareas de Codex por sprint.

Uso esperado:

- Mantener aquí el prompt completo o una referencia segura del sprint.
- No incluir secretos, tokens, certificados, `.env` ni datos reales.
- Actualizar `codex/current-task.md` con la tarea vigente antes de ejecutar.
- Usar `codex/next-task.md` para preparar la próxima tarea y disparar la creación automática de Issue.
